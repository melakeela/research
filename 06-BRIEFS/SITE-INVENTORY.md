# Site inventory

Every HTML file at the repository root: 133 pages, listed alphabetically by filename.

For each page: the `<title>` element, the `<meta name="description">` content, and a one-line
description of what the page covers, drawn from its own `<h1>`–`<h3>` headings.
All 133 pages have both a title and a meta description. Two pages —
`artifact-atlas.html` and `mlecha.html` — carry no headings in the HTML itself; their headings are
rendered at runtime by their JavaScript, and the descriptions below are taken from that source.
