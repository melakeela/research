This directory integrates programme planning into the research repository. It
does not change historical findings, evidence statuses, controllers,
constitutions, validators or site code.

## Files

- `canonical-programme-register.csv` — 221 rows: 133 intended current pages
  plus 88 canonical backlog programmes preserving all 89 BL source identifiers.
- `site-route-gap-map.csv` — one row for each of the 133 root public routes.
- `release-portfolio.md` — Release 1 centred on Atlas v2, Keezhadi PROVE IT and
  WATER, with enabler, audience-validation, safety and parallel-research roles.
- `execution-queue.csv` — dependency-ordered research, design, review and later
  implementation queue.

The exact complete backlog is preserved separately at
`06-BACKLOG/MELAKEELA-89-ITEM-MASTER-EXECUTION-PROMPT-v1.md`.

## Authority and provenance

1. Explicit owner decisions and corrections.
2. Exact original source documents.
3. Accepted content on current main branches.
4. Open pull requests as pending proposals only.
5. Handoffs and AI summaries as inherited leads.

The full backlog is an exact historical/source document. Status terms appearing
inside it do not establish a second operative repository vocabulary. The
programme register's `recommended_route_action`, `recommended_release` and
`release_role` columns are report-scoped planning fields, not claim statuses or
new persistent identifier namespaces. Route slugs and existing BL identifiers
are retained as row keys.

material exists. Completion requires the item-specific evidence, editorial,
